# Flight 404 — Side-View Seat Rows

Six replacement scenery modules showing aircraft seats from the aisle-side
profile rather than face-on seat backs.

- Seats face right in a flat side-scrolling composition.
- Shallow top surfaces and material shading provide restrained 3D volume.
- Each module is 72 × 42 logical units, delivered natively at 216 × 126.
- These files retain native high-resolution detail; they were not reduced to
  logical size and enlarged again.
- Every PNG has real transparency and a shared bottom ground line.

Variants cover upright seats, mixed recline angles, trays, stuffed pockets,
bags, pillows, blankets, cups, wrappers and other cabin clutter.
