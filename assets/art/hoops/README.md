# assets/art/hoops

Drop hoops art here. The build globs this folder — there is no manifest to edit
and no import to add. A file lands, the game uses it; a file is missing, the
coded pixel art draws instead.

See `docs/HOOPS-ART-BRIEF.md` for what each asset is, the exact pixel size, and
a description you can paste into an image generator.

Naming: `<sprite-id>.png`, or `<sprite-id>@<frames>.png` when the frame count
differs from the brief. Frames run left to right in one row, equal width, no
padding.

Send raw generator output if that is easier — stripping backgrounds, slicing
frames and downscaling on the pixel grid is a five-minute job on this side.
